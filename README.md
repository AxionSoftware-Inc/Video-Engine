# Engine

Standalone copy of the visualizer stack from MethodsLab.

Included:
- `app/video-lab`
- `packages/visual-engine`
- `packages/video-engine`
- `packages/scene-dsl`
- `packages/methods-engine`

Run locally:

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```
